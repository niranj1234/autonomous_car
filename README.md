This project focuses on developing an autonomous vehicle prototype equipped with Advanced Driver Assistance Systems (ADAS), using Arduino and the Pixy2 vision sensor. The system is designed to demonstrate key ADAS features such as:

	- Forward Collision Control
	- Adaptive Cruise Control
	- Lane Keeping
	- Traffic Light Recognition
	- Speed Regulation based on Traffic Sign Detection

A key component of this project is speed control, implemented to demonstrate a closed-loop control system.

Building on our previous project — an object-following robot — this iteration incorporates additional sensors, a PID control algorithm (developed using MATLAB), and real-time feedback to enhance system performance.

With growing familiarity in using the Pixy2 camera, we are now exploring its advanced features such as line detection and tracking for lane keeping and traffic sign recognition for speed regulation. Ultrasonic sensors are used to implement the forward collision avoidance functionality.
